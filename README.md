# Extended Lua Control System

Эта демонстрационная реализация описывает модульную систему управления на Lua, включающую подсистемы перемещения, взаимодействия с окружением, аналитику, визуализацию и интерактивный интерфейс.

## Структура проекта

- `main.lua` — точка входа, демонстрирующая интеграцию всех модулей.
- `src/core` — базовая инфраструктура: логирование, конфигурации, событийная шина, обработка ошибок и цикл обновления.
- `src/control` — системы управления перемещением и окружением.
- `src/analytics` — аналитика, визуализация показателей и подсветка объектов.
- `src/interface` — панель управления, предпросмотр, темы и фоновые эффекты.
- `src/modules` — дополнительные компоненты: автоматизация, инструменты работы с объектами, модификаторы среды, анализ производительности, камера и мониторинг.
- `src/rendering` — упрощённый рендерер для пакетной отрисовки.

## Возможности

- Альтернативные режимы навигации (direct/pathfind/orbit), управление высотой и плавные переходы.
- Настройка коллизий, автоматическое применение физических параметров и модификации среды.
- Отслеживание характеристик участников, система приоритетов, сглаживание показателей и визуализация дистанций.
- Графические индикаторы, цветовая кодировка, подсветка через препятствия и динамическая прозрачность.
- Панель управления с вкладками, поиск и фильтрация, а также интерактивный предпросмотр функций.
- Темы оформления с настройкой палитры, типографики, прозрачности и анимированными фонами.
- Дополнительные модули для автоматизации процессов, анализа производительности, расширенных настроек камеры и журналирования.
- Модульная архитектура с системой конфигураций, обработкой ошибок и обновлением компонентов.

## Запуск

Для запуска демонстрационного сценария требуется интерпретатор Lua 5.3 или выше:

```bash
lua main.lua
```

Скрипт выполнит серию обновлений, после чего выведет активное содержимое панели и текущие визуальные индикаторы.
