## CS2Scanner

В репозитории добавлен проект `CS2Scanner` — настольное WinForms-приложение для сбора системной информации и генерации HTML-отчёта по безопасности, оформленного в стиле отчёта CS2. При запуске приложение отправляет код подтверждения в Discord webhook, ожидает ввод кода, а затем выполняет следующие действия:

- Сбор сведений об операционной системе, оборудовании, времени работы ПК и пользователях.
- Анализ активных процессов, поиск подозрительных процессов и файлов (включая DLL/ZIP/EXE с известными ключевыми словами).
- Проверка выбранных ключей реестра и чтение файла `nvAppTimestamps` из каталога NVIDIA DRS.
- Формирование HTML-отчёта на основе предоставленного шаблона и отправка его обратно в Discord webhook.

### Сборка

Проект рассчитан на Windows и использует .NET 7.0. Для сборки откройте терминал в каталоге `CS2Scanner` и выполните команду:

```bash
dotnet build
```

После сборки выполнить приложение можно через:

```bash
dotnet run
```

> ⚠️ Для корректной работы требуется запуск под Windows с правами, достаточными для чтения системных каталогов, реестра и файла `nvAppTimestamps`.
