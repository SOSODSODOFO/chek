# Chek Scanner

WinForms-приложение «CS2 Scan Report» размещено в проекте [ChekScanner](ChekScanner/). Приложение создаёт насыщенную визуально панель проверки с плавными анимациями и тёмным фоном 400×400. Основной сценарий работы:

1. При запуске генерируется случайный код из 6 символов и отправляется в заданный Discord web-hook.
2. Пользователь вводит код. После успешной проверки поле ввода плавно исчезает, появляется подсказка и кнопка «Start Scan».
3. Нажатие кнопки запускает системный анализ: собирается информация об ОС, железе, пользователях, сети, а также формируется перечень процессов, подозрительных файлов и ключей реестра. Результат отображается в таблицах и карточках, а внизу выводится итоговый вердикт.

Чтобы открыть проект в Visual Studio, загрузите решение [ChekScanner.sln](ChekScanner.sln). Проект таргетирует .NET 6 (Windows) и требует пакета `System.Management` для доступа к WMI.
