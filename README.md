# CS2 Scanner

Пример проекта Windows Forms (.NET 6), который при запуске собирает информацию о системе,
формирует HTML-отчёт и отправляет его в Discord webhook.

## Сборка

1. Откройте решение `CS2Scanner.sln` в Visual Studio 2022 или новее.
2. Убедитесь, что установлен .NET 6.0 (Windows) SDK.
3. Соберите и запустите конфигурацию `Debug | Any CPU`.

При запуске приложение отправляет одноразовый шестизначный код в настроенный Discord webhook
и отображает экран приветствия. После ввода полученного кода и нажатия кнопки **Start**
запускается сбор системных данных, формируется отчёт и выгружается HTML-файл в webhook.
