# ChekScanner

WinForms-приложение «CS2 Deep Scan», выполняющее расширенное сканирование системы на предмет подозрительных процессов, файлов и записей реестра, собирающее телеметрию о железе и формирующее HTML-отчёт.

## Основные возможности

- Экран авторизации с одноразовым кодом (6 символов) и отправкой кода в Discord вебхук.
- Плавное раскрытие основного интерфейса после ввода кода и запуск проверки.
- Сбор системной информации (ОС, аппаратные характеристики, аптайм, VPN и пр.).
- Анализ процессов, папок и ключей реестра с выделением потенциально читерских артефактов.
- Парсинг файла `nvAppTimestamps` NVIDIA DRS и помещение найденных записей в таблицу отчёта.
- Генерация HTML-отчёта в стиле из задания и отправка файла в тот же Discord вебхук.

## Структура

- `ChekScanner/` — проект WinForms (`net8.0-windows`).
  - `MainForm.cs` — визуальная часть и сценарий взаимодействия пользователя.
  - `SystemScanner.cs` — вся логика сбора данных и эвристик.
  - `HtmlReportBuilder.cs` — формирование итогового HTML-отчёта.
  - `DiscordWebhookClient.cs` — утилита отправки сообщений и файлов в Discord.

## Сборка и запуск

1. Убедитесь, что установлен .NET 8 SDK с поддержкой Windows Desktop (рабочая нагрузка «Разработка классических приложений .NET» в Visual Studio). Проект настроен на использование последней установленной патч-версии референсного пакета, поэтому достаточно актуальной установки .NET 8:

   ```bash
   dotnet restore ChekScanner
   dotnet build ChekScanner -c Release
   ```

2. Запускайте из Windows (приложение использует WinForms и WMI):

   ```bash
   dotnet run --project ChekScanner -c Release
   ```

По завершении сканирования HTML-отчёт сохраняется в `Документы/CS2_ScanReports` и одновременно отправляется в указанный Discord вебхук.
